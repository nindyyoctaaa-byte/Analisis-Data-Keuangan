Informasi Penyimpanan & Batasan Teknologi
  • Penyimpanan Lokal (localStorage): Seluruh data transaksi, pengeluaran, dan profil bisnis tersimpan di browser pada perangkat ini. Data tetap aman saat halaman ditutup atau dimuat ulang, tetapi tidak otomatis tersinkronisasi ke perangkat lain.
  • Keamanan & Privasi: Website ini berjalan 100% di sisi klien (statis) tanpa mengirim data usaha Anda ke server pihak ketiga.
  • Fitur Cloud/AI Generatif: Untuk sinkronisasi multi-perangkat, sistem akun online, atau integrasi AI generatif (LLM), diperlukan backend server yang aman agar API key tidak terekspos di file HTML.
